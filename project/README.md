# Documentation

This folder contains all project documentation, organized by category.

## ⭐ START HERE

**[ROADMAP.md](./ROADMAP.md)** - **Official specification and single source of truth**

The ROADMAP defines the two-phase system architecture, mechanics, and rules for the Onchain World Cup. All implementations must follow this specification.

## 📁 Folder Structure

### `/contracts`
Smart contract specifications for both system phases.

- **QUALIFICATION_CONTRACT_SPEC.md** - Qualification phase contract (fixed-price voting)
- **TOURNAMENT_CONTRACT_SPEC.md** - Tournament phase match contracts (dynamic pricing)

### `/architecture`
High-level system architecture and design documents.

- **TWO_PHASE_SYSTEM.md** - Complete two-phase architecture overview

### `/database`
Database schema, migration guides, and data structure documentation.

- **TOURNAMENT_STRUCTURE.md** - Tournament database design
- **SUPABASE_SETUP.md** - Supabase configuration guide

### `/planning`
Implementation plans, code reviews, and analysis documents created during project planning.

- **PLAN.md** - Comprehensive implementation plan for two-phase system
- **V0_CODE_REVIEW.md** - Code review of V0-generated UI with fixes needed
- **pricing_analysis.md** - Analysis of 2-phase pricing mechanism (Tournament phase)
- **platform_earnings_calculation.md** - Platform fee and earnings calculations
- **CONTRACT_PRICING_FIX_NEEDED.md** - [DEPRECATED] Old contract issues

### `/reference`
Reference documentation and external resources.

- **farcaster_docs.md** - Farcaster integration documentation and requirements

### `/v0-generated`
Documentation generated by V0 during UI creation.

- **CM_01_02_STYLE_GUIDE.md** - V0 style guide for the app
- **SEO_CHECKLIST.md** - SEO optimization checklist from V0
