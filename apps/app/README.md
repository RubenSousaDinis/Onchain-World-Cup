# Onchain World Cup - Main App

The main application for the Onchain World Cup tournament.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Smart Contracts

Compile contracts:
```bash
npm run compile
```

Run tests:
```bash
npm run test
```

Deploy:
```bash
npm run deploy:sepolia  # Deploy to Base Sepolia testnet
npm run deploy:mainnet  # Deploy to Base mainnet
```

## Build

```bash
npm run build
```

## Deploy

Deploy to Vercel to serve at `app.onchainworldcup.xyz`
