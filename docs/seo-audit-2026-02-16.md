## Prioritized Action Plan

### 🔴 Critical — Fix This Week

#### 1. Add canonical tags to both domains
**File:** `apps/app/app/layout.tsx`

Both `onchainworldcup.xyz` and `app.onchainworldcup.xyz` return HTTP 200 with no `<link rel="canonical">`. Google is splitting link equity between two domains. This is the single highest-impact fix.

```ts
// apps/app/app/layout.tsx
export const metadata: Metadata = {
  metadataBase: new URL("https://onchainworldcup.xyz"),
  alternates: { canonical: "https://onchainworldcup.xyz" },
  // ...
}
```

#### 2. Fix the sitemap — 8 of 9 routes are missing
**File:** `apps/app/app/sitemap.ts`

The live `onchainworldcup.xyz/sitemap.xml` contains only 1 URL. The source `sitemap.ts` defines 9 routes but they all go to `app.onchainworldcup.xyz`. Verify `NEXT_PUBLIC_APP_DOMAIN=https://onchainworldcup.xyz` in Vercel env vars, and add database-driven dynamic routes for `/qualification/[countryId]`, `/teams/[teamId]`, and `/matches/[matchId]`.

Recommended `sitemap.ts` structure:

```ts
import type { MetadataRoute } from "next"
import { prisma } from "@/lib/prisma"

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const baseUrl = process.env.NEXT_PUBLIC_APP_DOMAIN || "https://app.onchainworldcup.xyz"

  const [matches, teams, countries] = await Promise.all([
    prisma.match.findMany({ select: { id: true, updatedAt: true } }),
    prisma.country.findMany({ select: { id: true, updatedAt: true } }),
    prisma.country.findMany({ select: { id: true, updatedAt: true } }),
  ])

  const staticRoutes: MetadataRoute.Sitemap = [
    { url: baseUrl, lastModified: new Date("2026-02-14") },
    { url: `${baseUrl}/qualification`, lastModified: new Date("2026-02-14") },
    { url: `${baseUrl}/teams`, lastModified: new Date("2026-02-14") },
    { url: `${baseUrl}/leaderboard`, lastModified: new Date("2026-02-14") },
    { url: `${baseUrl}/schedule`, lastModified: new Date("2026-02-14") },
    { url: `${baseUrl}/tournament`, lastModified: new Date("2026-02-14") },
    { url: `${baseUrl}/stats`, lastModified: new Date("2026-02-14") },
    { url: `${baseUrl}/how-it-works`, lastModified: new Date("2026-01-01") },
    // /my-bets excluded — user-specific, not indexable
  ]

  const matchRoutes = matches.map((m) => ({
    url: `${baseUrl}/matches/${m.id}`,
    lastModified: m.updatedAt,
  }))

  const teamRoutes = teams.map((t) => ({
    url: `${baseUrl}/teams/${t.id}`,
    lastModified: t.updatedAt,
  }))

  const qualificationRoutes = countries.map((c) => ({
    url: `${baseUrl}/qualification/${c.id}`,
    lastModified: c.updatedAt,
  }))

  return [...staticRoutes, ...matchRoutes, ...teamRoutes, ...qualificationRoutes]
}
```

  className="h-8 w-8"

#### 21. Increase mobile body font from 15px to 16px
Prevents iOS auto-zoom triggers on form inputs and interactive elements.

#### 22. Increase touch targets to 48px minimum
Social icon links (Twitter, Farcaster, Zora, email) and CTA buttons are 44–45px — 4px short of the WCAG 2.5.5 recommendation. Add 2–4px vertical padding.

#### 23. Add security headers
- `X-Content-Type-Options: nosniff`
- A Content-Security-Policy, especially given ETH transaction functionality
- Review `access-control-allow-origin: *` on the main document (wildcard CORS is unusual)

#### 24. Launch a content blog
The entire site is one indexable URL. 3–5 articles targeting "World Cup 2026 crypto", "how to vote onchain", "Base gaming 2026" would capture informational traffic and build topical authority.

#### 25. Expand FAQ answers
Current FAQ answers average ~30 words. Google's Helpful Content standards favor comprehensive answers of 100–200 words each.

#### 26. Remove `/my-bets` from app sitemap
User-specific page that returns generic content without wallet auth. Remove or add `noindex`.

#### 27. Fix duplicate H3 elements in the timeline
"Qualification Opens", "Qualification Ends", "Onchain World Cup Final", "Real World Cup" each appear twice in the DOM. Add `aria-hidden="true"` to the hidden duplicate or investigate the root cause in the timeline component.

#### 28. Add a visual hero element
The hero section is text-only with no imagery, flags, or visual metaphors. A subtle world map, country flags grid, or trophy illustration would increase emotional engagement and reduce bounce rate.
