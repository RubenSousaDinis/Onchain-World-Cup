## Remaining Issues (by priority)

### High

**1. Sitemap missing /about, /privacy-policy, /terms**
All three pages exist with canonical tags but are not in `sitemap.xml`. Google may be slow to discover them.
- File: `apps/landing/app/sitemap.ts` — add the three routes

**2. logo.svg returns 404 — OG image is missing the logo**
`opengraph-image.tsx` fetches `/logo.svg` which 404s. The generated social card has no logo. Every share card is broken.
- File: `apps/landing/app/opengraph-image.tsx` — change `/logo.svg` → `/logo.png`

**3. Event schema missing endDate, description, image**
Without `endDate` the schema does not qualify for Google's Event rich results.
- File: `apps/landing/app/layout.tsx` — add the three fields to the Event block

### Medium

**4. FAQPage JSON-LD not implemented**
12 detailed FAQ answers (100–200 words each) are server-rendered but not wrapped in `FAQPage` schema. Direct opportunity for FAQ rich results and AI citation.
- File: `apps/landing/app/layout.tsx` or `faq-section.tsx`

**5. Organization schema missing logo field**
Required for Google Knowledge Panel eligibility.
- File: `apps/landing/app/layout.tsx` — add `"logo": "https://onchainworldcup.xyz/logo.png"`

**6. manifest.json not linked from `<head>`**
File exists at `/manifest.json` but there is no `<link rel="manifest">` in the HTML. PWA install and browser discovery fail silently.
- File: `apps/landing/app/layout.tsx` — add `manifest: "/manifest.json"` to the metadata object

**7. Mobile "App →" touch target too small**
Button uses `py-1.5` → ~26px rendered height. Needs `min-h-[48px]` or `py-3`.
- File: `apps/landing/components/header.tsx`

### Low / Backlog
